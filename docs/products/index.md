# 作品

自己动手做、并且真的在线上跑着的小东西，免费使用，打开就能玩。

## 起身

> 久坐打断器：身体真的动起来，计时才会走完。

<https://standup.gclhaha.top/>

给每一个坐了太久的人。开启摄像头后，只有检测到你在动，这一组倒计时才会继续走完——所以它没法像番茄钟那样挂在那儿干等，只能真的站起来活动一下。

- 一组 30 / 60 / 90 秒，可选，隔一段时间提醒一次
- 姿态识别在浏览器本地完成，摄像头画面和运动记录都不上传
- 免登录，不需要安装 App

## 肌记

> 训练记录与肌群卡片：每一块练过的肌肉都会记得。

<https://muscle.gclhaha.top/>

记录今天的训练，然后生成一张标出目标肌群的分享卡片，练到哪儿一目了然，也方便发出去打个卡。

- 记录当天的训练内容
- 生成带肌群标注的分享卡片

## 为什么要做这些

写在这个博客的[构建](/building/)栏目里：业余时间做点小东西，跑通「想法 → 上线 → 有人用」的闭环，比单纯攒技术点有意思得多。产品很小，但都是自己会用的。
